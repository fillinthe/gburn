GBurn Link

Lets gburn.app (in your browser) talk to a Ruida laser on your network.

1. Double-click gburn-link (macOS: right-click > Open the first time). A window says "listening on ws://127.0.0.1:7451".
2. Keep it open. In gburn.app > Laser, pick "Ruida (network)", set the laser address in Machine Settings, Connect.

It only accepts connections from this computer and only relays to private network addresses.
