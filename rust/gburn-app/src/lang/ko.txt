The Layer settings in the panel: speed in mm/s, power in % of the machine's maximum, passes, and for Fill the line interval (DPI) and scan angle. Changes apply at once; ⌘Z undoes them.	패널의 레이어 설정: 속도(mm/s), 출력(장비 최대의 %), 패스 수, 채우기는 라인 간격 (DPI)과 스캔 각도. 변경은 바로 적용되고 ⌘Z로 되돌릴 수 있습니다.
Show, hide or skip a layer	레이어 보이기, 숨기기, 건너뛰기
On the layer's row: the eye shows or hides it in the design (hidden shapes can't be picked); the switch is Output: on = sent to the laser, off = designed only. Both are in the layer settings too.	레이어 행에서: 눈 아이콘은 디자인에서 보이거나 숨깁니다(숨긴 도형은 고를 수 없음). 스위치는 가공 출력: 켜기 = 레이저로 보냄, 끄기 = 디자인만. 둘 다 레이어 설정에도 있습니다.
Edit every layer setting in one window	모든 레이어 설정을 한 창에서 편집하기
Double-click a layer, or Laser › Cut Settings Editor.	레이어를 더블클릭하거나 레이저 › 컷 설정 편집기.
See the kerf	커프 보기
A Line layer with a kerf shows the offset outline dashed on the canvas: what the beam's centre will follow.	커프가 설정된 선 레이어는 오프셋된 윤곽을 캔버스에 점선으로 보여 줍니다: 빔 중심이 따라갈 경로입니다.
Kerf, tabs and cut order	커프, 탭, 컷 순서
On a Line layer: Kerf offset grows (+) or shrinks (−) the cut by half the beam; Tabs leaves bridges so parts stay put; Inner first cuts holes before outlines.	선 레이어에서: 커프 보정은 빔의 절반만큼 컷을 키우거나(+) 줄입니다(−). 탭은 부품이 떨어지지 않게 브리지를 남기고, 안쪽 먼저는 윤곽보다 구멍을 먼저 자릅니다.
Change the cut order	컷 순서 바꾸기
Layers cut in the order of the list, top first. The ▲ ▼ beside the layer name move it; × removes an empty layer. Inside a layer, Inner first cuts holes before outlines.	레이어는 목록 순서대로 위에서부터 잘립니다. 레이어 이름 옆의 ▲ ▼로 옮기고, ×로 빈 레이어를 지웁니다. 레이어 안에서는 안쪽 먼저가 윤곽보다 구멍을 먼저 자릅니다.
Lead-ins, overcut, cut direction	리드인, 오버컷, 컷 방향
Line layer › Lead-in: closed shapes start this far off the line, in the waste (outside a part, inside a hole), so the pierce mark isn't on the piece. Overcut runs on past the start. Direction: clockwise or anticlockwise.	선 레이어 › 리드인: 닫힌 도형은 선에서 이만큼 떨어진 버리는 쪽(부품 바깥, 구멍 안쪽)에서 시작하므로 관통 자국이 제품에 남지 않습니다. 오버컷은 시작점을 지나 더 자릅니다. 방향: 시계 방향 또는 반시계 방향.
Choose where a cut starts	컷 시작 위치 정하기
Select a closed shape, right-click its outline › Start the Cut Here (or Nodes tool › pick a point › Start here). A green dot marks it; the planner keeps it. Right-click › Clear the Start Point undoes it.	닫힌 도형을 선택하고 윤곽을 오른쪽 클릭 › 여기서 컷 시작(또는 노드 도구 › 점 선택 › 여기서 시작). 초록 점이 표시되고 플래너가 이를 지킵니다. 오른쪽 클릭 › 시작점 지우기로 취소합니다.
Perforate (dashed cut)	타공 (점선 컷)
On a Line layer: Perforation cut / skip lengths, e.g. 3 mm cut, 1 mm skip, for fold lines or tear-offs.	선 레이어에서: 타공 컷 / 건너뛰기 길이, 예: 3 mm 컷, 1 mm 건너뛰기. 접는 선이나 절취선에 씁니다.
Wobble and hatch families	워블과 해치 방향 바꾸기
Line layer › Wobble: diameter and spacing of small circles along the line (wider, smoother lines; deep galvo marking). Fill layer › Turn per pass: with Passes 2+ each pass hatches at a new angle.	선 레이어 › 워블: 선을 따라 그리는 작은 원의 지름과 간격(더 넓고 부드러운 선, 깊은 갈바노 마킹). 채우기 레이어 › 패스마다 회전: 패스 수가 2 이상이면 패스마다 새 각도로 해치합니다.
Dot mode and offset fill	도트 모드와 오프셋 채우기
Line layer › Dot mode fires N ms every D mm along the outline (acrylic dotting, perforating boards). Mode › Offset fill engraves in concentric insets, less travel on round shapes. Fill shapes one by one keeps each shape's lines together.	선 레이어 › 도트 모드는 윤곽을 따라 D mm마다 N ms씩 발사합니다(아크릴 도트, 보드 타공). 모드 › 오프셋 채우기는 동심 안쪽 선으로 각인해 둥근 도형에서 이동이 줄어듭니다. 도형별로 채우기를 켜면 각 도형의 선이 한데 모입니다.
Engrave and cut the same shapes	같은 도형을 각인하고 자르기
Select the layer, press + Sub-layer: a second set of settings (mode, speed, power…) runs on the same shapes right after the first. Main / Sub 1 / Sub 2 pick which one the panel edits.	레이어를 고르고 + 하위 레이어를 누릅니다: 두 번째 설정 묶음(모드, 속도, 출력…)이 첫 번째 바로 다음에 같은 도형에 실행됩니다. 메인 / 하위 1 / 하위 2로 패널이 편집할 쪽을 고릅니다.
Use my LightBurn material library	LightBurn 재료 라이브러리 쓰기
Laser › Import Material Library (.clb) (or drop the file on the canvas): every cut setting becomes a Material preset.	레이저 › 재료 라이브러리 가져오기 (.clb)(또는 파일을 캔버스에 놓기): 모든 컷 설정이 재료 프리셋이 됩니다.
Find the right speed and power	알맞은 속도와 출력 찾기
Laser › Material Test makes a grid: pick what changes down the side and across (speed, power, interval, passes, frequency or Z offset), a layer per cell with the current layer's other settings. Burn it and read the best cell's settings off its layer. Save settings you like as a material (the layer's Material › Save…).	레이저 › 재료 테스트가 그리드를 만듭니다: 세로와 가로로 바꿀 항목(속도, 출력, 간격, 패스 수, 주파수, Z 오프셋)을 고르면 칸마다 현재 레이어의 나머지 설정을 가진 레이어가 생깁니다. 가공한 뒤 가장 좋은 칸의 레이어에서 설정을 읽습니다. 마음에 드는 설정은 재료로 저장하세요(레이어의 재료 › 저장…).
Put a tab exactly where I want it	원하는 위치에 탭 넣기
Select the shape, right-click its outline › Add a Tab Here (the layer's tab length, Line layers). Right-click › Clear the Tabs removes them. With no hand-placed tabs, the layer's Tabs count spaces them evenly.	도형을 선택하고 윤곽을 오른쪽 클릭 › 여기에 탭 추가(레이어의 탭 길이, 선 레이어). 오른쪽 클릭 › 탭 지우기로 없앱니다. 직접 놓은 탭이 없으면 레이어의 탭 개수만큼 고르게 배치됩니다.
Cut shared edges once	공유 모서리는 한 번만 자르기
Machine Settings › Shared edges: cut once. Where two shapes on a Line layer share an edge (puzzles, grids, box joints), the second pass over it is left out: less charring, less time.	장비 설정 › 공유 모서리: 한 번만 컷. 선 레이어의 두 도형이 모서리를 공유하면(퍼즐, 격자, 상자 짜맞춤) 두 번째 통과를 생략합니다: 그을음도 시간도 줄어듭니다.
Switch between my lasers	여러 레이저 사이 전환하기
Laser › Machine Settings: set one machine up, type its name and press Save as a new machine; set up the next one the same way. Pick a machine at the top of Machine Settings or in the Laser tab (disconnected). The machine in use keeps every change.	레이저 › 장비 설정: 장비 하나를 설정하고 이름을 입력한 뒤 새 장비로 저장을 누릅니다. 다음 장비도 같은 방법으로 설정합니다. 장비 설정 맨 위나 레이저 탭(연결 해제 상태)에서 장비를 고릅니다. 사용 중인 장비는 모든 변경을 유지합니다.
Change the bed (work area)	베드(작업 영역) 바꾸기
Click empty canvas (nothing selected): the Bed card in the panel has the machine (Thunder Nova 63, galvo lenses…) or any size, where the design sits on it, Centre the design.	캔버스의 빈 곳을 클릭(아무것도 선택 안 함): 패널의 베드 카드에서 장비(Thunder Nova 63, 갈바노 렌즈…)나 원하는 크기, 베드 위 디자인의 위치, 디자인을 중앙으로를 정합니다.
Set the bed size and travel speed	베드 크기와 이동 속도 설정하기
Laser › Machine Settings: bed, travel speed and acceleration (the time estimate), full-power S ($30), baud rate, M4 / M3.	레이저 › 장비 설정: 베드, 이동 속도와 가속도(시간 예측용), 최대 출력 S ($30), 보드레이트, M4 / M3.
Run a fibre / galvo marker (EZCAD2)	파이버 / 갈바노 마커 (EZCAD2) 쓰기
Laser › Machine Settings: the lens field size and the EZCAD .cor correction file for your lens (ask the maker; it sets the field too), fibre or CO2 source. Pick “Galvo (EZCAD2 USB)” and Connect (Windows needs the WinUSB driver). Layers get a frequency (kHz) and MOPA pulse width. The design is centred on the field. Frame runs the red pointer; Start marks.	레이저 › 장비 설정: 렌즈 필드 크기와 렌즈용 EZCAD .cor 보정 파일(제조사에 문의, 필드도 함께 설정됨), 파이버 또는 CO2 소스. “Galvo (EZCAD2 USB)”를 고르고 연결합니다(Windows는 WinUSB 드라이버 필요). 레이어에 주파수 (kHz)와 MOPA 펄스 폭이 생깁니다. 디자인은 필드 중앙에 놓입니다. 프레임은 빨간 포인터로, 시작은 마킹을 합니다.
Run a Ruida / Thunder CO2 laser	Ruida / Thunder CO2 레이저 쓰기
Laser › Machine Settings: the controller's network address and its home corner (Thunder: rear left), then pick “Ruida (network)” and Connect. Home, jog, Frame (beam off), Start, Pause, Stop work like GRBL. In the browser, start GBurn Link on this computer first (gburn.app/download/). No network? File › Export Ruida (.rd) and run the file from a USB stick.	레이저 › 장비 설정: 컨트롤러의 네트워크 주소와 원점 모서리(Thunder: 뒤쪽 왼쪽)를 정한 뒤 “Ruida (network)”를 고르고 연결합니다. 원점 복귀, 조그, 프레임(빔 꺼짐), 시작, 일시 정지, 정지는 GRBL과 같습니다. 브라우저에서는 먼저 이 컴퓨터에서 GBurn Link를 실행하세요(gburn.app/download/). 네트워크가 없나요? 파일 › Ruida 내보내기 (.rd) 후 USB 메모리에서 파일을 실행합니다.
Use the galvo on Windows	Windows에서 갈바노 쓰기
EZCAD2's driver and GBurn's can't both own the board. Close EZCAD2, run Zadig (zadig.akeo.ie), Options › List All Devices, pick USBLMCV2 (9588 9899), WinUSB, Replace Driver. Then Galvo (EZCAD2 USB) › Connect. To go back, uninstall the device with its driver in Device Manager and reinstall EZCAD2's. Linux: a udev rule for 9588:9899 (docs/galvo-usb-drivers.md).	EZCAD2의 드라이버와 GBurn의 드라이버는 보드를 동시에 쓸 수 없습니다. EZCAD2를 닫고 Zadig (zadig.akeo.ie)을 실행, Options › List All Devices, USBLMCV2 (9588 9899), WinUSB를 고르고 Replace Driver. 그다음 Galvo (EZCAD2 USB) › 연결. 되돌리려면 장치 관리자에서 드라이버와 함께 장치를 제거하고 EZCAD2 드라이버를 다시 설치합니다. Linux: 9588:9899용 udev 규칙 (docs/galvo-usb-drivers.md).
Correct a galvo lens without a .cor file	.cor 파일 없이 갈바노 렌즈 보정하기
Laser › Galvo Lens Test Pattern adds a square at 80 % of the field; mark it at low power and measure it. Too small: raise Scale. Sides bowed in: raise Bulge; out: lower it. Top wider than the bottom: lower Trapezoid X. Leaning: Skew. Machine Settings › Galvo; mark again until it measures right.	레이저 › 갈바노 렌즈 테스트 패턴은 필드의 80 % 크기 정사각형을 추가합니다. 낮은 출력으로 마킹하고 재 보세요. 너무 작으면: 배율을 올립니다. 변이 안쪽으로 휘면: 볼록을 올리고, 바깥으로 휘면 내립니다. 위가 아래보다 넓으면: 사다리꼴 X를 내립니다. 기울었으면: 기울이기. 장비 설정 › 갈바노. 치수가 맞을 때까지 다시 마킹합니다.
Connect a GRBL laser over Wi-Fi or Ethernet	Wi-Fi나 이더넷으로 GRBL 레이저 연결하기
FluidNC and grblHAL boards speak Telnet (port 23): Machine Settings › GRBL network address, then pick “GRBL (network…)” and Connect. In the browser, run GBurn Link on this computer first.	FluidNC와 grblHAL 보드는 Telnet(포트 23)을 씁니다: 장비 설정 › GRBL 네트워크 주소를 입력한 뒤 “GRBL (network…)”를 고르고 연결합니다. 브라우저에서는 먼저 이 컴퓨터에서 GBurn Link를 실행하세요.
Use a rotary	로터리 쓰기
Machine Settings › Rotary on Y: the Y travel per full turn (jog to check) and the object's diameter. Y is scaled so the design wraps the object; X stays as drawn.	장비 설정 › Y축 로터리: 한 바퀴당 Y 이동량(조그로 확인)과 물체의 지름. 디자인이 물체를 감싸도록 Y가 배율 조정되고, X는 그린 그대로입니다.
Find the focus (Z axis lasers)	초점 찾기 (Z축 레이저)
Material Test with Z offset down the side (for example −2 to 2 mm, 9 rows) and one power: the sharpest row's Z is the focus. Then set the layer's Z offset, or move the bed.	세로를 Z 오프셋(예: −2 ~ 2 mm, 9행)으로, 출력은 하나로 재료 테스트: 가장 선명한 행의 Z가 초점입니다. 그다음 레이어의 Z 오프셋을 정하거나 베드를 움직입니다.
Frame with a red-dot pointer that sits beside the beam	빔 옆에 있는 빨간 점 포인터로 프레임하기
Laser › Machine Settings › Red-dot pointer: how far the dot is from the beam, X and Y in mm (measure it: fire a dot, move the head until the pointer is on it, read the move). Frame then runs the dot round the design.	레이저 › 장비 설정 › 빨간 점 포인터: 점이 빔에서 얼마나 떨어져 있는지 X와 Y를 mm로(재는 법: 점 하나를 발사하고 포인터가 그 위에 올 때까지 헤드를 움직인 뒤 이동량을 읽음). 그러면 프레임이 디자인 둘레로 점을 움직입니다.
Make the time estimate match my machine	시간 예측을 내 장비에 맞추기
Laser › Machine Settings › Time estimate ×: if jobs take 20 % longer than the estimate, type 1.2.	레이저 › 장비 설정 › 시간 예측 ×: 작업이 예측보다 20 % 오래 걸리면 1.2를 입력합니다.
Add my own G-code buttons	나만의 G-code 버튼 추가하기
Laser › Machine Settings › Macros: + Macro, a name and the lines to send. The buttons appear under the Console in the Laser tab (GRBL, not mid-job). Start / End G-code there go round every job.	레이저 › 장비 설정 › 매크로: + 매크로, 이름과 보낼 줄. 버튼은 레이저 탭의 콘솔 아래에 나타납니다(GRBL, 작업 중에는 불가). 그곳의 시작 / 종료 G-code는 모든 작업의 앞뒤에 붙습니다.
Find the spot (Fire)	빔 위치 찾기 (발사)
Machine Settings › Fire button, then Fire in the Laser panel: a short low-power pulse (GRBL). Eye protection on. Ruida: the Pulse key on the machine.	장비 설정 › 발사 버튼을 켠 뒤 레이저 패널의 발사: 짧은 저출력 펄스(GRBL). 보안경을 쓰세요. Ruida: 장비의 Pulse 키.
Choose where the laser starts	레이저 시작 위치 정하기
Laser panel › Start from: Bed (absolute) = the design burns where it sits on the bed; Current position = it starts where the head is now (LightBurn's Current Position) (pick the job origin on the 3 × 3 grid: which corner, edge or the centre); User origin = a saved spot (Set origin). An orange cross shows the job origin on the canvas.	레이저 패널 › 시작 위치: 베드 (절대) = 디자인이 베드 위 놓인 자리에서 가공됩니다. 현재 위치 = 헤드가 지금 있는 곳에서 시작합니다(LightBurn의 Current Position)(3 × 3 그리드에서 작업 원점 선택: 어느 모서리, 변, 또는 가운데). 사용자 원점 = 저장한 위치(원점 설정). 캔버스의 주황색 십자가 작업 원점을 표시합니다.
Set a user origin	사용자 원점 설정하기
Jog the head to the spot and press Set origin (Laser panel), or right-click the canvas › Set the user origin here. Machine Settings › Start from › User origin puts the job's origin point there.	헤드를 그 위치로 조그하고 원점 설정(레이저 패널)을 누르거나, 캔버스를 오른쪽 클릭 › 여기를 사용자 원점으로 설정. 장비 설정 › 시작 위치 › 사용자 원점으로 작업 원점이 그곳이 됩니다.
Start the job where the head is	헤드 위치에서 작업 시작하기
Laser › Machine Settings › Start from: Current position, with a job origin (bottom-left, centre…). Jog the head to that spot on the material and Start; the G-code sets it with G92.	레이저 › 장비 설정 › 시작 위치: 현재 위치와 작업 원점(왼쪽 아래, 가운데…). 헤드를 재료 위 그 지점으로 조그하고 시작. G-code가 G92로 그 위치를 설정합니다.
Frame the job	작업 프레임하기
Frame traces the outline of the design (or the selection) with the beam off, so you can place the material.	프레임은 빔을 끈 채 디자인(또는 선택 영역)의 윤곽을 따라가므로 재료를 놓을 자리를 맞출 수 있습니다.
Burn the design	디자인 가공하기
Start sends the job. Pause / Resume (Space) and Stop are always in the panel; Stop resets the controller.	시작이 작업을 보냅니다. 일시 정지 / 재개(Space)와 정지는 항상 패널에 있습니다. 정지는 컨트롤러를 리셋합니다.
See the order and the time	순서와 시간 보기
P previews the job: strokes in their layer colours, travel dashed, a time estimate from your machine settings.	P로 작업을 미리봅니다: 선은 레이어 색으로, 이동은 점선으로 표시되고 장비 설정에 따른 시간 예측이 나옵니다.
Simulate the job	작업 시뮬레이션하기
In Preview, ▶ plays the job at 1×, 4× or 16× real time: the head moves along the strokes, travel dashed, the clock and the stroke count above. Drag the slider to any moment.	미리보기에서 ▶는 실제 시간의 1×, 4×, 16×로 작업을 재생합니다: 헤드가 선을 따라 움직이고, 이동은 점선, 위에 시계와 선 개수가 나옵니다. 슬라이더를 드래그해 원하는 순간으로 갑니다.
Watch the job (simulation)	작업 지켜보기 (시뮬레이션)
Preview (P, or the switch at the top) shows the job; the bar under the canvas plays it. Speed − / + steps from ¼× to 256× real time (the slider goes in between); drag the long slider to any moment.	미리보기(P 또는 맨 위의 전환)가 작업을 보여 주고, 캔버스 아래 막대가 재생합니다. 속도 − / +는 실제 시간의 ¼×부터 256×까지 단계별로 바뀌고(슬라이더로 중간값도), 긴 슬라이더를 드래그하면 원하는 순간으로 갑니다.
See how it might look on wood	나무에서 어떻게 보일지 미리 보기
Preview › the bar's last list: Birch plywood, Maple, Cherry, Walnut, Bamboo, MDF, Cork, Cardboard, Leather, Slate, anodised aluminium, acrylic. Fills show as solid areas, darker where the power is high for the speed. A rough guide: run a Material Test on the real thing.	미리보기 › 막대의 마지막 목록: 자작나무 합판, 메이플, 체리, 월넛, 대나무, MDF, 코르크, 골판지, 가죽, 슬레이트, 아노다이징 알루미늄, 아크릴. 채우기는 면으로 보이며, 속도에 비해 출력이 높을수록 진해집니다. 대략적인 안내일 뿐이니 실제 재료로 재료 테스트를 해 보세요.
Burn only part of the design	디자인 일부만 가공하기
Select the shapes and tick “Burn only the selected shapes” in the Laser panel; Frame follows the selection too. Machine Settings › Frame: the box or the outline (hull).	도형을 선택하고 레이저 패널에서 “선택한 도형만 가공”에 체크합니다. 프레임도 선택 영역을 따릅니다. 장비 설정 › 프레임: 박스 또는 윤곽(볼록 껍질).
Burn one part where the head is	헤드 위치에서 부품 하나 가공하기
Select the part, tick “Burn only the selected shapes”, Laser tab › Start from: Current position, and tick “of the selection” by the job origin: the job origin comes from that part's box.	부품을 선택하고 “선택한 도형만 가공”에 체크, 레이저 탭 › 시작 위치: 현재 위치, 작업 원점 옆의 “선택 영역의”에 체크: 작업 원점이 그 부품의 박스에서 정해집니다.
Move the head to an exact spot	헤드를 정확한 위치로 옮기기
Laser tab › Go to X / Y: type X and Y, Go (beam off). Right-click › Move the laser here does the same for a spot on the canvas.	레이저 탭 › 이동… X / Y: X와 Y를 입력하고 이동(빔 꺼짐). 오른쪽 클릭 › 레이저를 여기로 이동은 캔버스의 한 지점에 대해 같은 일을 합니다.
Save head positions I go back to	자주 가는 헤드 위치 저장하기
Laser tab › Spots › + Save here remembers where the head is; the numbered buttons go back there (beam off).	레이저 탭 › 위치 메모 › + 여기 저장은 헤드 위치를 기억하고, 번호 버튼으로 그곳에 돌아갑니다(빔 꺼짐).
Change speed or power mid-job	작업 중 속도나 출력 바꾸기
GRBL lasers: the Speed and Power − / + under Start change the running job by 10 % at once (100 puts it back). Laser › GRBL Settings ($$) reads and writes the controller's settings.	GRBL 레이저: 시작 아래의 속도와 출력 − / +는 실행 중인 작업을 즉시 10 %씩 바꿉니다(100은 원래대로). 레이저 › GRBL 설정 ($$)은 컨트롤러의 설정을 읽고 씁니다.
Run a G-code file from another program	다른 프로그램의 G-code 파일 실행하기
Connect a GRBL laser, then Laser › Run a G-code File…, pick the file and press Start in its box. It goes as it is.	GRBL 레이저를 연결한 뒤 레이저 › G-code 파일 실행…에서 파일을 고르고 그 창의 시작을 누릅니다. 파일은 그대로 전송됩니다.
Export for another program	다른 프로그램용으로 내보내기
File › Export G-code (GRBL, mm, M4) or Export SVG. LightBurn, SVG and DXF files import.	파일 › G-code 내보내기(GRBL, mm, M4) 또는 SVG 내보내기. LightBurn, SVG, DXF 파일은 가져올 수 있습니다.
See the material on the bed (camera)	베드 위 재료 보기 (카메라)
Laser › Camera Overlay…: Take a photo (browser camera above the bed) or Load a photo (a phone shot from above). Click the bed corners, or four marks you burnt, in order and type where they are; Place on the bed. The photo lies under the design, never burnt; the marks are kept, so the next photo goes straight on.	레이저 › 카메라 오버레이…: 사진 찍기(베드 위 브라우저 카메라) 또는 사진 불러오기(위에서 찍은 휴대폰 사진). 베드 모서리나 직접 새긴 네 개의 표시를 순서대로 클릭하고 위치를 입력한 뒤 베드에 배치. 사진은 디자인 아래에 놓이며 가공되지 않습니다. 표시는 유지되므로 다음 사진은 바로 맞춰집니다.
Line up on a photo of the bed	베드 사진에 맞추기
Draw › Background Photo: a picture on a layer that never burns. Size and place it to match the bed or the object, lock it (⌘L), design on top.	그리기 › 배경 사진: 가공되지 않는 레이어의 이미지. 베드나 물체에 맞게 크기와 위치를 정하고 잠근 뒤(⌘L) 그 위에 디자인합니다.
Cut round a printed sheet (Print & Cut)	인쇄한 시트 둘레 자르기 (인쇄 후 컷)
Laser › Print & Cut: put two marks in the design (small crosses or circles near opposite corners), print it, lay the sheet on the bed. Select mark 1, Use the selection; same for mark 2. Jog the laser onto the real mark 1, press Laser is on it; same for mark 2. Align turns and moves the whole design onto the sheet. Frame to check, then Start.	레이저 › 인쇄 후 컷: 디자인에 표시 두 개(대각 근처의 작은 십자나 원)를 넣고 인쇄한 뒤 시트를 베드에 놓습니다. 표시 1을 선택하고 선택 영역 사용, 표시 2도 같게 합니다. 레이저를 실제 표시 1로 조그하고 레이저가 위치함을 누르고, 표시 2도 같게 합니다. 정렬이 디자인 전체를 돌리고 옮겨 시트에 맞춥니다. 프레임으로 확인한 뒤 시작.
Find the centre of a round part	둥근 부품의 중심 찾기
Laser › Centre Finder…: jog the head to three points on the part's edge, pressing Here at each; it shows the centre and diameter. Move the head there, or set the user origin there and Start from the user origin.	레이저 › 중심 찾기…: 헤드를 부품 가장자리의 세 점으로 조그하며 각각에서 여기를 누르면 중심과 지름이 나옵니다. 헤드를 그곳으로 옮기거나, 그곳을 사용자 원점으로 정하고 사용자 원점에서 시작합니다.
