Se connecter (le compte GCarve fonctionne ici) : Fichier › Enregistrer dans le compte garde le design ; Ouvrir depuis le compte les liste. Réenregistre tout seul 3 s après une modification.
Get the design back after a crash	Récupérer le design après un plantage
A recovery copy is written 3 s after every change and offered back at the next start.	Une copie de récupération est écrite 3 s après chaque modification et proposée au démarrage suivant.
Go back several steps	Revenir plusieurs étapes en arrière
Edit › Undo History: every change by name (Move, Resize, Change layer…, the command's name). Click a step to go back to just before it; click a dim (undone) one to bring the steps back.	Édition › Historique d'annulation : chaque modification par son nom (Déplacer, Redimensionner, Changer de calque…, le nom de la commande). Cliquez une étape pour revenir juste avant ; cliquez une étape grisée (annulée) pour rétablir les étapes.

File › Notes: saved inside the .gburn file.	Fichier › Notes : enregistrées dans le fichier .gburn.
Move my settings to another computer	Transférer mes réglages sur un autre ordinateur
File › Export Settings… saves your machines, materials, templates, lens file, snap and units to one file. On the other computer (or in the browser): File › Import Settings….	Fichier › Exporter les réglages… enregistre vos machines, matériaux, modèles, fichier de lentille, aimant et unités dans un seul fichier. Sur l'autre ordinateur (ou dans le navigateur) : Fichier › Importer les réglages….
Open a .plt (HPGL) file	Ouvrir un fichier .plt (HPGL)
File › Import takes .plt / .hpgl plot files from CorelDRAW, sign software and cutters: each pen becomes a layer.	Fichier › Importer accepte les fichiers de traçage .plt / .hpgl de CorelDRAW, des logiciels d'enseignes et des plotters de découpe : chaque stylo devient un calque.
Draw a rectangle, circle or line	Dessiner un rectangle, un cercle ou une ligne
R, E and L pick the tools (or the tool bar); drag on the canvas. Hold ⇧ for a square, a circle, or 5 mm snapping. Enter finishes a line; clicking its first point closes it.	R, E et L choisissent les outils (ou la barre d'outils) ; faites glisser sur le canevas. Maintenez ⇧ pour un carré, un cercle ou un aimant de 5 mm. Entrée termine une ligne ; cliquer sur son premier point la ferme.
Draw curves	Dessiner des courbes
Line tool (L): click = a corner, click and drag = a smooth point (the drag pulls out its curve). Click the first point to close; Enter or double-click ends an open line.	Outil Ligne (L) : clic = un angle, cliquer-glisser = un point lisse (le glissement tire sa courbe). Cliquez le premier point pour fermer ; Entrée ou un double-clic termine une ligne ouverte.
Set the exact size or position	Définir la taille ou la position exacte
Select the shapes: the X / Y / W / H boxes in the panel take typed sizes (12, 1/2in, 30mm). Enter applies.	Sélectionnez les formes : les champs X / Y / W / H du panneau acceptent des tailles saisies (12, 1/2in, 30mm). Entrée applique.
See a shape's properties	Voir les propriétés d'une forme
Select one shape: the panel shows its kind, point count, length and area, a name, Close / Open path and Reverse (the cut direction), besides X / Y / W / H and Rotate.	Sélectionnez une forme : le panneau affiche son type, son nombre de points, sa longueur et son aire, un nom, Fermer / Ouvrir le tracé et Inverser (le sens de coupe), en plus de X / Y / W / H et Rotation.
Measure a distance	Mesurer une distance
M (Measure): drag between two points; the distance, Δx, Δy and angle show in the status bar.	M (Mesurer) : faites glisser entre deux points ; la distance, Δx, Δy et l'angle s'affichent dans la barre d'état.
Snap to a grid	Aimanter à une grille
The Snap menu in the status bar: off, 0.5 / 1 / 5 / 10 mm or 1/16 / 1/8 / 1/4 in. ⇧ while drawing always snaps to 5 mm.	Le menu Aimant de la barre d'état : désactivé, 0,5 / 1 / 5 / 10 mm ou 1/16 / 1/8 / 1/4 in. ⇧ pendant le dessin aimante toujours à 5 mm.
Edit the points of a shape	Modifier les points d'une forme
N (Nodes): click a shape, drag its points; double-click a segment to add a point; ⌫ removes the picked one. The picked point's X / Y are in the panel: type exact values and press Enter. Make corner / Make smooth, Next ▸ steps along the path.	N (Nœuds) : cliquez une forme, faites glisser ses points ; double-cliquez un segment pour ajouter un point ; ⌫ supprime celui choisi. Les X / Y du point choisi sont dans le panneau : saisissez des valeurs exactes et appuyez sur Entrée. En angle / Adoucir, Suivant ▸ avance le long du tracé.
Node keys	Touches des nœuds
In the Nodes tool, point at a point or a segment and press: D delete, I insert a point, M a point at the middle, C corner, S smooth (a segment: curve), L straight, B break, T trim, E extend an open end, A turn the shape so the segment is level / upright / 45°. ⇧-click or a box picks several points; the arrow keys move them; drop an open end on another to join.	Dans l'outil Nœuds, pointez un point ou un segment et appuyez sur : D supprimer, I insérer un point, M un point au milieu, C angle, S lisse (un segment : courbe), L droit, B couper, T rogner, E prolonger une extrémité ouverte, A tourner la forme pour que le segment soit horizontal / vertical / à 45°. ⇧-clic ou un cadre choisit plusieurs points ; les flèches les déplacent ; déposez une extrémité ouverte sur une autre pour les joindre.
Join or cut shapes together	Combiner ou découper des formes
Select two or more closed shapes: Shapes › Union, Subtract (the first minus the rest) or Intersect. Offset Shapes makes a parallel copy; Round Corners rounds a closed shape.	Sélectionnez deux formes fermées ou plus : Formes › Union, Soustraire (la première moins le reste) ou Intersection. Décaler les formes crée une copie parallèle ; Arrondir les angles arrondit une forme fermée.
Group shapes	Grouper des formes
Select them and press ⌘G: they select and move as one from then on; ⇧⌘G ungroups. Imported files and traced pictures come in grouped.	Sélectionnez-les et appuyez sur ⌘G : dès lors elles se sélectionnent et se déplacent ensemble ; ⇧⌘G dégroupe. Les fichiers importés et les images vectorisées arrivent groupés.
Copy, paste, lock	Copier, coller, verrouiller
⌘C / ⌘X / ⌘V (⇧⌘V pastes at the right-click spot), ⌘L locks the selection so it can't be picked or moved (⇧⌘L unlocks everything). The right-click menu on the canvas has them all.	⌘C / ⌘X / ⌘V (⇧⌘V colle à l'endroit du clic droit), ⌘L verrouille la sélection pour qu'elle ne puisse être ni choisie ni déplacée (⇧⌘L déverrouille tout). Le menu du clic droit sur le canevas les contient tous.
Add a ready-made shape	Ajouter une forme toute faite
Draw › Shapes Library: hearts, stars, arrows, plaques, keyhole hangers, joints and more. Type the width, click a tile: it lands in the middle of the view on the current layer, grouped.	Dessiner › Bibliothèque de formes : cœurs, étoiles, flèches, plaques, attaches trou de serrure, assemblages et plus. Saisissez la largeur, cliquez une vignette : elle arrive au milieu de la vue sur le calque courant, groupée.
Keep my own art to reuse	Garder mes propres dessins pour les réutiliser
Select the shapes, Draw › Shapes Library… › My art, type a name, Save the selection. Click its tile in any design to add it at the typed width; right-click a tile to remove it. Export Settings carries it to another computer.	Sélectionnez les formes, Dessiner › Bibliothèque de formes… › Mes dessins, saisissez un nom, Enregistrer la sélection. Cliquez sa vignette dans n'importe quel design pour l'ajouter à la largeur saisie ; clic droit sur une vignette pour la retirer. Exporter les réglages l'emporte sur un autre ordinateur.
Repeat a shape along a line	Répéter une forme le long d'une ligne
Select the shape and a line or curve, Arrange › Copy Along Path: how many copies, turned with the path or not. The longest selected outline is the path.	Sélectionnez la forme et une ligne ou courbe, Disposer › Copier le long d'un chemin : combien de copies, tournées avec le chemin ou non. Le contour sélectionné le plus long est le chemin.
Line up or repeat shapes	Aligner ou répéter des formes
Arrange › Align (left, centre, right, top, middle, bottom) and Distribute lines the selection up; Grid Array repeats it in columns and rows with a gap.	Disposer › Aligner (gauche, centre, droite, haut, milieu, bas) et Répartir alignent la sélection ; Réseau en grille la répète en colonnes et rangées avec un écart.
Make live copies (virtual array)	Créer des copies liées (réseau virtuel)
Select the shapes, Arrange › Virtual Array…: columns, rows and gaps. The copies follow the original as you change or move it and burn as real shapes. Open it again with a copy selected to Update, Make the copies real or Remove.	Sélectionnez les formes, Disposer › Réseau virtuel… : colonnes, rangées et écarts. Les copies suivent l'original quand vous le modifiez ou le déplacez et se gravent comme de vraies formes. Rouvrez-le avec une copie sélectionnée pour mettre à jour, Rendre les copies réelles ou Retirer.
Clean up an imported drawing	Nettoyer un dessin importé
Shapes › Delete Duplicates and Specks (stacked copies would cut twice), Join Open Paths (ends within 0.05 mm), Close Paths, Simplify (fewer points, smoother motion), Weld.	Formes › Supprimer doublons et points isolés (des copies empilées couperaient deux fois), Joindre les chemins ouverts (extrémités à moins de 0,05 mm), Fermer les chemins, Simplifier (moins de points, mouvement plus fluide), Souder.
Pack parts onto the material	Placer les pièces sur le matériau
Arrange › Nest on the Bed packs the selection (or everything) by its boxes, groups kept together, turned 90° when it fits better.	Disposer › Imbriquer sur le plateau range la sélection (ou tout) selon ses cadres, groupes gardés ensemble, tournés de 90° quand ça tient mieux.
Add text	Ajouter du texte
T opens the Text box: words (several lines), height, font (any font on this computer, or Font file…), letter spacing, line gap, alignment. The letters land on the current layer, centred on the view, grouped; select them and Edit text… to change the words later.	T ouvre la boîte Texte : les mots (plusieurs lignes), la hauteur, la police (toute police de cet ordinateur, ou Fichier de police…), l'espacement des lettres, l'interligne, l'alignement. Les lettres arrivent sur le calque courant, centrées dans la vue, groupées ; sélectionnez-les puis Modifier le texte… pour changer les mots plus tard.
Merge names from a spreadsheet (CSV)	Fusionner des noms depuis un tableur (CSV)
Text box › Data file (CSV)… (or drop a .csv on the canvas): the first row names the columns. Type {name} (any column) in a text; ◀ ▶ pick the row; every Start burns the current row and moves to the next.	Boîte Texte › Fichier de données (CSV)… (ou déposez un .csv sur le canevas) : la première ligne nomme les colonnes. Tapez {name} (n'importe quelle colonne) dans un texte ; ◀ ▶ choisissent la ligne ; chaque Démarrer grave la ligne courante et passe à la suivante.
Text on a path, serial numbers, dates	Texte sur un chemin, numéros de série, dates
Select a line or closed shape, open the Text box (T) and tick “Along the selected shape”. Type {n} for a serial number ({n:4} zero-padded), {date} or {time}: every Start stamps the current number and counts up (the next number is in the Text box).	Sélectionnez une ligne ou une forme fermée, ouvrez la boîte Texte (T) et cochez « Le long de la forme sélectionnée ». Tapez {n} pour un numéro de série ({n:4} complété de zéros), {date} ou {time} : chaque Démarrer inscrit le numéro courant et compte (le numéro suivant est dans la boîte Texte).
Put text round a circle	Mettre du texte autour d'un cercle
Select the circle (or any shape), open Text, tick Along the selected shape: the text centres on the top, outside. Tick inside for text along the bottom inside the circle; moved % slides it round.	Sélectionnez le cercle (ou toute forme), ouvrez Texte, cochez Le long de la forme sélectionnée : le texte se centre en haut, à l'extérieur. Cochez intérieur pour du texte en bas à l'intérieur du cercle ; décalé % le fait tourner.
Bend text into an arc	Courber du texte en arc
Select the text or shapes, Shapes › Bend / Taper…: Bend is the arc in degrees (180 = a half circle, − bends the other way), Top width narrows or widens the top for a tapered cup. Number boxes take sums too: 100/3, 2in + 5mm.	Sélectionnez le texte ou les formes, Formes › Courber / Effiler… : Courber est l'arc en degrés (180 = un demi-cercle, − courbe dans l'autre sens), Largeur du haut rétrécit ou élargit le haut pour un gobelet conique. Les champs numériques acceptent aussi des calculs : 100/3, 2in + 5mm.
Make a QR code or barcode	Créer un code QR ou un code-barres
Draw › QR Code / Barcode: QR, Data Matrix, Code 128, Code 39, Code 93, EAN-13, EAN-8, UPC-A, Codabar or Interleaved 2 of 5; the text and a size. It lands on the current layer as squares or bars (engrave with Fill). Test-scan a burnt one.	Dessiner › Code QR / Code-barres : QR, Data Matrix, Code 128, Code 39, Code 93, EAN-13, EAN-8, UPC-A, Codabar ou Interleaved 2 of 5 ; le texte et une taille. Il arrive sur le calque courant en carrés ou en barres (à graver en Remplissage). Testez la lecture d'un code gravé.
Engrave a picture	Graver une image
Draw › Picture (or drop a PNG / JPEG on the canvas): it lands on an Image layer. Set its size in the panel; on the layer pick the image mode (dither, ordered, greyscale), the line interval (DPI), negative and overscan.	Dessiner › Image (ou déposez un PNG / JPEG sur le canevas) : elle arrive sur un calque Image. Réglez sa taille dans le panneau ; sur le calque, choisissez le mode image (tramage, ordonné, niveaux de gris), l'intervalle de ligne (DPI), négatif et surcourse.
Adjust a picture	Ajuster une image
Select the picture: Brightness, Contrast and Gamma sliders apply before the dither; Negative is on the layer.	Sélectionnez l'image : les curseurs Luminosité, Contraste et Gamma s'appliquent avant le tramage ; Négatif est sur le calque.
Turn a picture into vectors	Transformer une image en vecteurs
Select a picture and use Draw › Trace Picture: the dark parts (or the light ones) become outlines on a Trace layer, ready to cut or fill.	Sélectionnez une image et utilisez Dessiner › Vectoriser l'image : les parties sombres (ou claires) deviennent des contours sur un calque Trace, prêts à couper ou remplir.
Trace line art as single lines	Vectoriser un dessin au trait en lignes simples
Select the picture, Draw › Trace Picture…, switch on Centerline: one line along each stroke instead of its outline (signatures, handwriting, line drawings for one pass or a pen).	Sélectionnez l'image, Dessiner › Vectoriser l'image…, activez Ligne médiane : une ligne le long de chaque trait au lieu de son contour (signatures, écriture, dessins au trait pour un seul passage ou un stylo).
Cut a photo to a shape	Découper une photo selon une forme
Select the picture and a closed shape over it (a circle, a heart), Draw › Cut the Picture to the Shape: outside the shape goes white (not burnt).	Sélectionnez l'image et une forme fermée par-dessus (un cercle, un cœur), Dessiner › Découper l'image à la forme : l'extérieur de la forme devient blanc (non gravé).
Engrave shapes as a picture	Graver des formes comme une image
Select closed shapes, Draw › Turn Shapes into a Picture: they become a picture on the Image layer at its line interval, so its dither applies.	Sélectionnez des formes fermées, Dessiner › Convertir les formes en image : elles deviennent une image sur le calque Image à son intervalle de ligne, donc son tramage s'applique.
Engrave a relief (3D) on a fibre laser	Graver un relief (3D) au laser fibre
Put a greyscale picture on an Image layer, Image mode › 3D slices, and Passes = the number of depth levels (10–30). Each pass burns everything darker than its level, so the darkest parts get every pass and go deepest.	Mettez une image en niveaux de gris sur un calque Image, Mode image › Tranches 3D, et Passes = le nombre de niveaux de profondeur (10–30). Chaque passe grave tout ce qui est plus sombre que son niveau : les parties les plus sombres reçoivent toutes les passes et vont le plus profond.
Cut, score or engrave	Couper, marquer ou graver
Each layer has a mode: Line follows the outline (cut or score), Fill scans the inside (engrave). Click a layer to draw on it, or to move the selected shapes onto it.	Chaque calque a un mode : Ligne suit le contour (couper ou marquer), Remplissage balaie l'intérieur (graver). Cliquez un calque pour dessiner dessus, ou pour y déplacer les formes sélectionnées.
Set speed and power	Régler la vitesse et la puissance
The Layer settings in the panel: speed in mm/s, power in % of the machine's maximum, passes, and for Fill the line interval (DPI) and scan angle. Changes apply at once; ⌘Z undoes them.	Les réglages du calque dans le panneau : vitesse en mm/s, puissance en % du maximum de la machine, passes, et pour Remplissage l'intervalle de ligne (DPI) et l'angle de balayage. Les changements s'appliquent aussitôt ; ⌘Z les annule.
Show, hide or skip a layer	Afficher, masquer ou ignorer un calque
On the layer's row: the eye shows or hides it in the design (hidden shapes can't be picked); the switch is Output: on = sent to the laser, off = designed only. Both are in the layer settings too.	Sur la ligne du calque : l'œil l'affiche ou le masque dans le design (les formes masquées ne peuvent pas être choisies) ; l'interrupteur est Sortie : activé = envoyé au laser, désactivé = dessin seulement. Les deux sont aussi dans les réglages du calque.
Edit every layer setting in one window	Modifier tous les réglages des calques dans une fenêtre
Double-click a layer, or Laser › Cut Settings Editor.	Double-cliquez un calque, ou Laser › Éditeur de réglages de coupe.
See the kerf	Voir le kerf
A Line layer with a kerf shows the offset outline dashed on the canvas: what the beam's centre will follow.	Un calque Ligne avec un kerf affiche le contour décalé en pointillés sur le canevas : ce que suivra le centre du faisceau.
Kerf, tabs and cut order	Kerf, attaches et ordre de coupe
On a Line layer: Kerf offset grows (+) or shrinks (−) the cut by half the beam; Tabs leaves bridges so parts stay put; Inner first cuts holes before outlines.	Sur un calque Ligne : Décalage de kerf agrandit (+) ou réduit (−) la coupe d'un demi-faisceau ; Attaches laisse des ponts pour que les pièces restent en place ; Intérieur d'abord coupe les trous avant les contours.
Change the cut order	Changer l'ordre de coupe
Layers cut in the order of the list, top first. The ▲ ▼ beside the layer name move it; × removes an empty layer. Inside a layer, Inner first cuts holes before outlines.	Les calques sont coupés dans l'ordre de la liste, du haut vers le bas. Les ▲ ▼ à côté du nom du calque le déplacent ; × retire un calque vide. Dans un calque, Intérieur d'abord coupe les trous avant les contours.
Lead-ins, overcut, cut direction	Entrées, surcoupe, sens de coupe
Line layer › Lead-in: closed shapes start this far off the line, in the waste (outside a part, inside a hole), so the pierce mark isn't on the piece. Overcut runs on past the start. Direction: clockwise or anticlockwise.	Calque Ligne › Entrée : les formes fermées commencent à cette distance de la ligne, dans la chute (hors d'une pièce, dans un trou), pour que la marque de perçage ne soit pas sur la pièce. Surcoupe continue au-delà du départ. Sens : horaire ou antihoraire.
Choose where a cut starts	Choisir où commence une coupe
Select a closed shape, right-click its outline › Start the Cut Here (or Nodes tool › pick a point › Start here). A green dot marks it; the planner keeps it. Right-click › Clear the Start Point undoes it.	Sélectionnez une forme fermée, clic droit sur son contour › Commencer la coupe ici (ou outil Nœuds › choisir un point › Démarrer ici). Un point vert le marque ; le planificateur le garde. Clic droit › Effacer le point de départ l'annule.
Perforate (dashed cut)	Perforer (coupe en pointillés)
On a Line layer: Perforation cut / skip lengths, e.g. 3 mm cut, 1 mm skip, for fold lines or tear-offs.	Sur un calque Ligne : longueurs de coupe / saut de Perforation, p. ex. 3 mm de coupe, 1 mm de saut, pour des plis ou des détachables.
Wobble and hatch families	Oscillation et familles de hachures
Line layer › Wobble: diameter and spacing of small circles along the line (wider, smoother lines; deep galvo marking). Fill layer › Turn per pass: with Passes 2+ each pass hatches at a new angle.	Calque Ligne › Oscillation : diamètre et espacement de petits cercles le long de la ligne (lignes plus larges et plus lisses ; marquage galvo profond). Calque Remplissage › Rotation par passe : avec Passes 2+ chaque passe hachure sous un nouvel angle.
Dot mode and offset fill	Mode point et remplissage décalé
Line layer › Dot mode fires N ms every D mm along the outline (acrylic dotting, perforating boards). Mode › Offset fill engraves in concentric insets, less travel on round shapes. Fill shapes one by one keeps each shape's lines together.	Calque Ligne › Mode point tire N ms tous les D mm le long du contour (pointillé sur acrylique, perforation de cartons). Mode › Remplissage décalé grave en contours concentriques, moins de déplacements sur les formes rondes. Remplir les formes une à une garde les lignes de chaque forme ensemble.
Engrave and cut the same shapes	Graver et couper les mêmes formes
Select the layer, press + Sub-layer: a second set of settings (mode, speed, power…) runs on the same shapes right after the first. Main / Sub 1 / Sub 2 pick which one the panel edits.	Sélectionnez le calque, appuyez sur + Sous-calque : un second jeu de réglages (mode, vitesse, puissance…) s'exécute sur les mêmes formes juste après le premier. Principal / Sous 1 / Sous 2 choisissent celui que le panneau modifie.
Use my LightBurn material library	Utiliser ma bibliothèque de matériaux LightBurn
Laser › Import Material Library (.clb) (or drop the file on the canvas): every cut setting becomes a Material preset.	Laser › Importer une bibliothèque de matériaux (.clb) (ou déposez le fichier sur le canevas) : chaque réglage de coupe devient un préréglage de Matériau.
Find the right speed and power	Trouver la bonne vitesse et la bonne puissance
Laser › Material Test makes a grid: pick what changes down the side and across (speed, power, interval, passes, frequency or Z offset), a layer per cell with the current layer's other settings. Burn it and read the best cell's settings off its layer. Save settings you like as a material (the layer's Material › Save…).	Laser › Test de matériau crée une grille : choisissez ce qui varie en hauteur et en largeur (vitesse, puissance, intervalle, passes, fréquence ou décalage Z), un calque par case avec les autres réglages du calque courant. Gravez-la et lisez les réglages de la meilleure case sur son calque. Enregistrez les réglages qui vous plaisent comme matériau (Matériau › Enregistrer… du calque).
Put a tab exactly where I want it	Placer une attache exactement où je veux
Select the shape, right-click its outline › Add a Tab Here (the layer's tab length, Line layers). Right-click › Clear the Tabs removes them. With no hand-placed tabs, the layer's Tabs count spaces them evenly.	Sélectionnez la forme, clic droit sur son contour › Ajouter une attache ici (la longueur d'attache du calque, calques Ligne). Clic droit › Effacer les attaches les retire. Sans attaches placées à la main, le nombre d'Attaches du calque les répartit régulièrement.
Cut shared edges once	Couper une seule fois les bords communs
Machine Settings › Shared edges: cut once. Where two shapes on a Line layer share an edge (puzzles, grids, box joints), the second pass over it is left out: less charring, less time.	Réglages machine › Bords communs : couper une fois. Là où deux formes d'un calque Ligne partagent un bord (puzzles, grilles, assemblages à entailles), le second passage est supprimé : moins de brûlure, moins de temps.
Switch between my lasers	Passer d'un de mes lasers à l'autre
Laser › Machine Settings: set one machine up, type its name and press Save as a new machine; set up the next one the same way. Pick a machine at the top of Machine Settings or in the Laser tab (disconnected). The machine in use keeps every change.	Laser › Réglages machine : configurez une machine, saisissez son nom et appuyez sur Enregistrer comme nouvelle machine ; configurez la suivante de la même façon. Choisissez une machine en haut des Réglages machine ou dans l'onglet Laser (déconnecté). La machine utilisée garde chaque modification.
Change the bed (work area)	Changer le plateau (zone de travail)
Click empty canvas (nothing selected): the Bed card in the panel has the machine (Thunder Nova 63, galvo lenses…) or any size, where the design sits on it, Centre the design.	Cliquez sur un endroit vide du canevas (rien de sélectionné) : la carte Plateau du panneau propose la machine (Thunder Nova 63, lentilles galvo…) ou toute taille, l'endroit où le design s'y place, Centrer le design.
Set the bed size and travel speed	Régler la taille du plateau et la vitesse de déplacement

Laser › Motif de test de lentille galvo ajoute un carré à 80 % du champ ; marquez-le à faible puissance et mesurez-le. Trop petit : augmentez Échelle. Réglages machine › Galvo ; marquez à nouveau jusqu'à ce que la mesure soit juste.
