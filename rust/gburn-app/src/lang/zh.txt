Choose where a cut starts	选择切割起点
Select a closed shape, right-click its outline › Start the Cut Here (or Nodes tool › pick a point › Start here). A green dot marks it; the planner keeps it. Right-click › Clear the Start Point undoes it.	选择闭合形状，右键点击其轮廓 › 从这里开始切割（或 节点工具 › 选一个节点 › 从这里开始）。绿点作为标记；规划器会保留它。右键 › 清除起点 可撤销。
Perforate (dashed cut)	穿孔（虚线切割）
On a Line layer: Perforation cut / skip lengths, e.g. 3 mm cut, 1 mm skip, for fold lines or tear-offs.	在直线图层上：穿孔 的切 / 跳长度，例如切 3 mm、跳 1 mm，用于折线或撕线。
Wobble and hatch families	摆动和每遍换角度
Line layer › Wobble: diameter and spacing of small circles along the line (wider, smoother lines; deep galvo marking). Fill layer › Turn per pass: with Passes 2+ each pass hatches at a new angle.	直线图层 › 摆动：沿线小圆的直径和间距（更宽、更顺滑的线；振镜深打标）。填充图层 › 每遍旋转：遍数 2 以上时每遍以新角度填充。
Dot mode and offset fill	打点模式和偏移填充
Line layer › Dot mode fires N ms every D mm along the outline (acrylic dotting, perforating boards). Mode › Offset fill engraves in concentric insets, less travel on round shapes. Fill shapes one by one keeps each shape's lines together.	直线图层 › 打点模式 沿轮廓每 D mm 出光 N ms（亚克力打点、板材打孔）。模式 › 偏移填充 以同心内缩线雕刻，圆形形状空程更少。逐个填充形状 让每个形状的线集中在一起。
Engrave and cut the same shapes	对同一形状先雕刻再切割
Select the layer, press + Sub-layer: a second set of settings (mode, speed, power…) runs on the same shapes right after the first. Main / Sub 1 / Sub 2 pick which one the panel edits.	选择图层，按 + 子图层：第二组设置（模式、速度、功率…）在第一组之后紧接着作用于同一形状。主 / 子 1 / 子 2 选择面板编辑哪一组。
Use my LightBurn material library	使用我的 LightBurn 材料库
Laser › Import Material Library (.clb) (or drop the file on the canvas): every cut setting becomes a Material preset.	激光 › 导入材料库（.clb）（或把文件拖到画布上）：每个切割设置成为一个材料预设。
Find the right speed and power	找到合适的速度和功率
Laser › Material Test makes a grid: pick what changes down the side and across (speed, power, interval, passes, frequency or Z offset), a layer per cell with the current layer's other settings. Burn it and read the best cell's settings off its layer. Save settings you like as a material (the layer's Material › Save…).	激光 › 材料测试 生成网格：选择纵向和横向变化的项目（速度、功率、间距、遍数、频率或 Z 偏移），每个格子一个图层，其余设置沿用当前图层。加工后从最佳格子的图层读取设置。把满意的设置保存为材料（图层的 材料 › 保存…）。
Put a tab exactly where I want it	把连接点放在想要的位置
Select the shape, right-click its outline › Add a Tab Here (the layer's tab length, Line layers). Right-click › Clear the Tabs removes them. With no hand-placed tabs, the layer's Tabs count spaces them evenly.	选择形状，右键点击其轮廓 › 在此添加连接点（使用图层的连接点长度，直线图层）。右键 › 清除连接点 删除它们。没有手动放置的连接点时，按图层的连接点数量均匀分布。
Cut shared edges once	共享边只切一次
Machine Settings › Shared edges: cut once. Where two shapes on a Line layer share an edge (puzzles, grids, box joints), the second pass over it is left out: less charring, less time.	机器设置 › 共享边：只切一次。直线图层上两个形状共用一条边时（拼图、格栅、箱体榫接），省去第二次切割：焦痕更少，时间更短。
Switch between my lasers	在我的多台激光器间切换
Laser › Machine Settings: set one machine up, type its name and press Save as a new machine; set up the next one the same way. Pick a machine at the top of Machine Settings or in the Laser tab (disconnected). The machine in use keeps every change.	激光 › 机器设置：设置好一台机器，输入名称并按 另存为新机器；下一台同样设置。在机器设置顶部或激光标签页（未连接时）选择机器。正在使用的机器会保留每次修改。
Change the bed (work area)	更改工作台（工作区域）
Click empty canvas (nothing selected): the Bed card in the panel has the machine (Thunder Nova 63, galvo lenses…) or any size, where the design sits on it, Centre the design.	点击画布空白处（不选任何东西）：面板中的工作台卡片可设置机器（Thunder Nova 63、振镜镜头…）或任意尺寸、设计在台面上的位置、设计居中。
Set the bed size and travel speed	设置工作台尺寸和空程速度
Laser › Machine Settings: bed, travel speed and acceleration (the time estimate), full-power S ($30), baud rate, M4 / M3.	激光 › 机器设置：工作台、空程速度和加速度（用于时间估算）、满功率 S（$30）、波特率、M4 / M3。
Run a fibre / galvo marker (EZCAD2)	运行光纤 / 振镜打标机（EZCAD2）

Pick “Galvo (EZCAD2 USB)” and Connect (Windows needs the WinUSB driver). Layers get a frequency (kHz) and MOPA pulse width. The design is centred on the field. Frame runs the red pointer; Start marks.	激光 › 机器设置：镜头场尺寸以及适合你镜头的 EZCAD .cor 校正文件（向厂家索取；它也会设置场尺寸），光纤或 CO2 光源。选择“振镜（EZCAD2 USB）”并连接（Windows 需要 WinUSB 驱动）。图层增加频率（kHz）和 MOPA 脉宽。设计居中于场内。走边框 使用红光指示，开始 进行打标。
Run a Ruida / Thunder CO2 laser	运行 Ruida / Thunder CO2 激光器
Laser › Machine Settings: the controller's network address and its home corner (Thunder: rear left), then pick “Ruida (network)” and Connect. Home, jog, Frame (beam off), Start, Pause, Stop work like GRBL. In the browser, start GBurn Link on this computer first (gburn.app/download/). No network? File › Export Ruida (.rd) and run the file from a USB stick.	激光 › 机器设置：控制器的网络地址和原点角（Thunder：左后），然后选择“Ruida（网络）”并连接。回原点、点动、走边框（不出光）、开始、暂停、停止 与 GRBL 用法相同。在浏览器中，请先在本机启动 GBurn Link（gburn.app/download/）。没有网络？文件 › 导出 Ruida（.rd），再从 U 盘运行该文件。
Use the galvo on Windows	在 Windows 上使用振镜
EZCAD2's driver and GBurn's can't both own the board. Close EZCAD2, run Zadig (zadig.akeo.ie), Options › List All Devices, pick USBLMCV2 (9588 9899), WinUSB, Replace Driver. Then Galvo (EZCAD2 USB) › Connect. To go back, uninstall the device with its driver in Device Manager and reinstall EZCAD2's. Linux: a udev rule for 9588:9899 (docs/galvo-usb-drivers.md).	EZCAD2 的驱动和 GBurn 的驱动不能同时占用板卡。关闭 EZCAD2，运行 Zadig（zadig.akeo.ie），Options › List All Devices，选择 USBLMCV2（9588 9899）、WinUSB，Replace Driver。然后 振镜（EZCAD2 USB）› 连接。要恢复，在设备管理器中连同驱动卸载该设备，再重新安装 EZCAD2 的驱动。Linux：为 9588:9899 添加 udev 规则（docs/galvo-usb-drivers.md）。
Correct a galvo lens without a .cor file	没有 .cor 文件时校正振镜镜头
Laser › Galvo Lens Test Pattern adds a square at 80 % of the field; mark it at low power and measure it. Too small: raise Scale. Sides bowed in: raise Bulge; out: lower it. Top wider than the bottom: lower Trapezoid X. Leaning: Skew. Machine Settings › Galvo; mark again until it measures right.	激光 › 振镜镜头测试图案 添加一个场尺寸 80 % 的正方形；用低功率打标并测量。偏小：调高 缩放。边向内凹：调高 鼓形；向外凸：调低。上边比下边宽：调低 梯形 X。歪斜：调整 倾斜。机器设置 › 振镜；反复打标直到尺寸正确。
Connect a GRBL laser over Wi-Fi or Ethernet	通过 Wi-Fi 或以太网连接 GRBL 激光器

Use a rotary	使用旋转轴
